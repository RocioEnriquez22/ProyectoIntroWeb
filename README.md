 # Proyecto Introducción al Desarrollo Web
## Proyecto final del curso de extensión "Introducción al Desarrollo Web"
El proyecto trata sobre los parques nacionales de nuestro país. La idea es crear un sitio web interactivo, sencillo e informativo de fácil acceso para cualquier persona interesada en conocerlos.

 ## Descripción del Proyecto
Este proyecto es el trabajo final del curso de extensión, donde aplicamos lo aprendido de HTML, CSS y JavaScript para construir un sitio web. El objetivo es demostrar la capacidad de estructurar contenido, aplicar estilos responsivos e interactuar con el usuario a través de eventos y manipulación del DOM.

 ## Características Principales
Diseño Responsivo: Adaptado para verse correctamente en dispositivos móviles, tablets y escritorio (especialmente en la sección de cards.html).

Uso de JavaScript: Implementación de eventos y manipulación del DOM.

Navegación entre diferentes páginas web.

 Estructura del proyecto
 ```
 ProyectoIntroWeb/
├── css/           # Archivos CSS.
├── js/            # Archivos de JavaScript.
├── imgs/          # Imágenes.
├── pages/         # Páginas HTML adicionales (cards, y paginas de los parques).
├── index.html     # Página principal del sitio.
└── favicon.ico    # Icono de la pestaña del navegador.
```
